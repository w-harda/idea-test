# ADR：以属性条件更新收益指导G/H内部优化

状态：已实现，CPU验证通过；未授权GPU。日期：2026-11-16。

原Cooperative的四状态相似度差与Push-pull的Pull存在目标竞争。用户要求在内部优化中学习“怎样修改才能让对方下一步更有效”，同时保留攻击样本之间的Push-pull关系。

决策：

1. 不直接叠加旧四模式全局项。用隔离前瞻收益训练共享语义/历史评价器，指导G的原Top-K Local权重和H的属性/位置/替换学习。
2. 连续G采用有限候选一步前瞻蒸馏重加权；离散H采用完整局部合法条件动作期望优势及属性头监督。两侧保留原主目标及预算。
3. G→H探测包含完整K+1虚拟G更新与1次虚拟H更新；H→G探测明确只做1次全局G更新，避免重标记旧JVP。
4. 使用不同Train support/probe，无Test/Validation反馈。小型评价器只在训练运行，推理仍为G(I)、H(T)。
5. 语义键共享有界历史；Checkpoint包含评价器、Adam、记忆、Replay、RNG。真实与虚拟更新分别核对。
6. 保留前瞻局部Bank及固定合法轨迹支持集的近似身份，不能宣称完整图库重生成或完整策略期望。

详细算法、引用、代码入口及审计边界见[方法协议](../GH_ATTRIBUTE_RESPONSE.md)。
