# ADR-0017：双向协同训练目标与十轮审计边界

状态：用户授权实施，2026-11-09。

原GH-v2仅在原G/H方法间传递更新条件与图库；本次研究把模态交互纳入优化目标，独立命名GH-Cooperative-v1。

采用四模式协同分数、H逐编辑撤销贡献、G残余证据局部权重及同图多描述目标。继续保留G(I)/H(T)推理，所有配对、PID和第二描述留在训练监督。数值系数、seed、2048成员及六个Test节点在执行前冻结。原代码与60轮资产不修改。

使用≤4MiB严格JSON分片及Manifest封存所有训练记录，CPU逐片核对原预算和新增损失，保持全局64MiB限制。每十轮提交完整双模型/Adam/RNG/Bank边界，经CPU审计与该轮原生完整Joint Test/CPU审计后继续。真实失败不自动重试；只接续计划中的完整十轮边界。

单次组合实验考察六节点轨迹；本轮不增加单项消融或Test调参。启动后用户自行检查控制文件，助手不持续查看实验。
