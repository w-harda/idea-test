# ADR-0015：G/H双向条件交替的最小匹配控制

日期：2026-10-22。状态：CPU原型与设计采用；真实GPU实验待明确授权。

## 背景

G的S_raw与H的重要性分数并非同一监督；强制共享选择/K会引入额外算法变量。
旧JVP绑定原Caption，Unicode编辑后不可仅改Caption或SHA继续声称为新语境监督。
G/H历史Checkpoint与训练协议不可重写。

## 决定

保留G(I)、H(T)、原G K+1、原Loss及H SCST/Reward。
A1：G原条件，H最新完整Train bank。
B：G使用H文本的新语境z/定位/JVP，H最新完整Train bank。
固定原G的S_raw选择/顺序/K，原Canonical+H完整trace严格映射，不重新提取攻击文本属性。
原数据为2048/128，更新块8条×2轮；每轮完整2048图库刷新，全部Train-only反馈。
新组合父状态G60/H10，双Adam和分别管理的G/H阶段RNG，独立来源与round提交。
真实输入映射/源模型兼容性失败则停止，不退化成旧条件或加入新Loss。

## 影响

B改变实际监督输入，但不改变Loss函数或G前向接口，不能宣称旧训练轨迹不变。
本阶段只验证信息流，不承诺性能增益、不选Test最低模型、不启动60轮训练。
CPU Fixture证明控制流及恢复/拒绝规则；真实JVP、梯度和更新差仍需后续授权。
未完成round Claim禁止自动重播；保留原失败证据，不覆盖历史资产。
