# ADR-0001：冻结原件，渐进兼容

状态：接受（Stage 1用户授权）。背景：历史prototypes、缓存、Checkpoint、Selection存在严格源码/身份/SHA闭包，目录搬迁和公共工具替换可能破坏复现。

决定：在独立工作树和src/tbps新增契约、配置、独立资产存储与只读桥；历史代码、协议、结果不修改、不复制重写。先缓存/来源契约，再官方Adapter和评测等价，训练服务最后逐项适配。

理由：当前已有正式特征可复用，无需为了框架重训G/H；算法与来源必须保持独立。桥只说明实际验证范围，不能把header检查叫全资产审计。

影响：Stage 1没有真实执行入口和模型加载；旧绝对路径通过资产描述显式保留。新模型特征不能复用IRRA向量。Stage 2另行授权。
